# Temporary intentflow API verification repository

This public repository was created only to verify intentflow's GitHub review
API integration (pull diff, existing comments, comment/approve/request-changes).

Pull requests are closed and their branches are deleted. Safe to delete this
repository. It could not be deleted by the verification token because that
token lacks the `delete_repo` scope.

## Intentflow Actions demo

This branch adds a workflow that renders the pull request diff as a static
intentflow page and publishes it with GitHub Pages.
